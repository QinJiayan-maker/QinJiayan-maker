# 区块链电子合同 / 合同管理系统

[← 项目索引](../PROJECTS.md) · [代码（私有）](https://github.com/QinJiayan-maker/blockchain-contract)

## 我的职责

基于 RuoYi-Vue-Plus 完成电子合同管理系统的完整项目开发，覆盖合同与用户管理、PDF 盖章、Hyperledger Fabric 链码调用及 IPFS 文件存储等业务能力。

私有仓库保留对应的 `he_contract-master` 工程与项目说明。

## 技术构成

Java · Spring Boot · Vue · Hyperledger Fabric · IPFS · PDF 处理。

## 归属与状态

项目基于已有框架与组件实现，保留第三方代码的许可、说明和目录结构。

上传副本不包含私钥、证书密钥库、运行凭据和构建缓存；运行时必须重新配置自己的开发环境。本次没有连接区块链网络或执行交易。
