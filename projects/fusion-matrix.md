# 融矩阵 / 数字藏品平台

[← 项目索引](../PROJECTS.md) · [源码、表结构与项目文档（私有）](https://github.com/QinJiayan-maker/fusion-matrix)

## 实习实践

在北京市计算中心实习期间参与数字藏品平台后端开发。

- 基于 Spring Boot 提供藏品展示与用户基础能力。
- 以 MyBatis Plus 实现分类、稀有度、售卖状态等维度的分页筛选，并结合置顶与时间排序。
- 参与注册、登录、实名认证与用户信息查询等基础接口。

## 归档组织

原先的三个目录合并为一个私有项目仓库：

- `source/`：`fusion-matrix` Java 多模块工程。
- `database-schema/`：从 `fusion_matrix.sql` 提取的 14 张表结构，不包含原始业务记录。
- `project-docs/`：接口、架构、数据库设计、使用说明与测试 / 试运行文档。
