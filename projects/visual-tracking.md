# 视觉目标跟踪 / 从感知到控制

[← 项目索引](../PROJECTS.md) · [源码（私有，需授权）](https://github.com/QinJiayan-maker/visual-target-tracking)

## 项目概述

将目标检测与单目标跟踪连接到云台控制，让视觉识别结果进入实际的硬件交互流程。介绍依据本地项目 `track` 目录的文档整理，源码快照已整理至独立私有仓库。

## 核心链路

视频输入 → YOLO 检测 → NanoTrack 跟踪 → 卡尔曼滤波 → 串口通信 → STM32 舵机控制。

- **视觉处理**：组合目标检测与跟踪，加入卡尔曼滤波。
- **硬件联动**：通过串口与 STM32 控制工程连接，支持自动云台跟随。
- **交互方式**：提供 OpenCV 桌面窗口与 Web 模式；Web 界面包含视频流、串口控制和摄像头切换。

## 技术构成

Python · OpenCV · YOLO · NanoTrack · 卡尔曼滤波 · STM32 · 串口通信。
