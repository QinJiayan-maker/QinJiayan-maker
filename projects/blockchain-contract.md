# 区块链电子合同 / 项目归档

[← 项目索引](../PROJECTS.md) · [代码（私有）](https://github.com/QinJiayan-maker/blockchain-contract)

## 归档内容

本地 `he_contract-master` 是基于 RuoYi-Vue-Plus 的电子合同管理工程。现有说明涉及合同与用户管理、PDF 盖章、Hyperledger Fabric 链码调用及 IPFS 文件存储。

## 技术构成

Java · Spring Boot · Vue · Hyperledger Fabric · IPFS · PDF 处理。

## 归属与状态

保留已有框架与第三方代码的许可、说明和目录结构。这是代码归档介绍，不将框架、链码或全部业务实现描述成我的独立原创成果。个人负责的具体模块可后续核实补充。

上传副本不包含私钥、证书密钥库、运行凭据和构建缓存；运行时必须重新配置自己的开发环境。本次没有连接区块链网络或执行交易。
