# 金龙鱼 / 智能订单 Agent

[← 项目索引](../PROJECTS.md) · [源码（私有）](https://github.com/QinJiayan-maker/jinlongyu-order-agent)

## 场景

在业务员使用的 App 内嵌 H5 中展示建议订单，允许用户用文字、语音和拍照调整商品与数量，并衔接原生下单流程。

## 实践内容

- 用 Next.js H5 承载门店选择、建议订单、改单与反馈。
- 工具覆盖 SKU 搜索、批量增减改和待确认商品；区分商品 ID、SKU 编码与包装单位 ID。
- 控制单轮工具步数，遇到可能未处理完的批量操作时提示用户核对。
- 将语音与图片输入汇入同一改单链路，保留会话、订单草稿与调用日志。
- 区分客户只读业务库和应用读写库，并通过 JS Bridge 衔接原生页面。

## 技术与归档

Next.js · TypeScript · React · AI SDK · Prisma · PostgreSQL · ASR · OSS。

本地目录含两个实现版本，分别保留在私有仓库中，没有静默覆盖或合并源码。外部接口和企业配置需单独准备，本次上传不代表重新完成真实接口联调。
