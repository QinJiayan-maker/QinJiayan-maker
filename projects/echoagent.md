## 想解决什么

当个人 Agent 同时接触历史资料、表达风格和工具时，几个问题会一起出现：回答到底依据哪条记录？过去的事实是否仍然有效？AI 自己生成的内容会不会被当作本人记忆？工具应该在哪一步停下来等待确认？

EchoAgent 围绕这些问题，探索从授权资料到人物对话、再到受控执行的完整工作台。

## 关键设计

- **记忆与风格分开检索**：事实索引负责“知道什么”，风格索引负责“怎么表达”，分别保留来源。
- **时序事实与来源隔离**：区分当前与历史状态、原始资料与 AI 交互，支持来源更正、撤回和删除。
- **执行前确认**：以本地日历草稿为例，先展示执行摘要，由用户批准或拒绝，批准后可撤销。
- **可追踪的产品界面**：集中呈现聊天、人设、记忆、导入、反馈、事件追踪和费用。
- **隔离的演示环境**：以合成数据和独立 Docker Compose 环境演示导入、检索、审批与恢复流程。

## 技术构成

React / TypeScript 提供工作台；Python / FastAPI 提供 API；LangGraph 组织工作流；PostgreSQL / pgvector 承载数据与检索；Docker Compose 提供独立演示环境。
