# Disney DAM / 企业数字资产管理

[← 项目索引](../PROJECTS.md) · [源码与技术附件（私有）](https://github.com/QinJiayan-maker/disney-dam)

## 场景与职责

在企业数字资产管理系统中参与身份鉴权、多模态检索和私有化部署适配。归档包含 Java 后端、Python 媒体处理服务及两个前端工程。

## 实践内容

- 对接企业 MyID 登录与网关鉴权，统一用户、组织和业务身份信息。
- 基于角色控制素材访问，处理未完成角色配置的账号边界。
- 参与 Milvus 向量检索与 ETCD 配置适配，配合多模态素材解析与以图搜图。
- 区分私有素材的签名访问与 CDN 回源，结合内网环境处理构建配置与第三方依赖。

## 技术与归档

Java / Spring Boot · Python · React / TypeScript · Milvus · ETCD · 对象存储。

相关资产流程、网关与技术方案附件一并保存在私有仓库，公开页不展示企业架构细节、内网地址或凭据。本次归档未重跑原系统构建与客户环境联调。
